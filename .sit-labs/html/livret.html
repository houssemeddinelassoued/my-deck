Atelier 1 · Même tâche, deux outils

Objectif
Résumer le journal de l’incident FS-02 pour le directeur logistique, une fois avec Copilot, une fois avec Claude, avec exactement le même prompt, puis comparer les deux résultats sur une grille commune.
Fichiers
Orvalis/journal-incident-FS02.docx
Étapes
1
Répartissez-vous les outils
Une personne travaille dans Copilot (Copilot Chat ou Microsoft 365 Copilot), l’autre dans Claude. Joignez le journal d’incident dans chaque outil.
2
Envoyez le même prompt
Copiez-le mot pour mot dans les deux outils :
« Résume ce journal d’incident en dix lignes pour le directeur logistique : ce qui s’est passé, l’impact, la durée, ce qui est fait pour que ça ne recommence pas. Pas de jargon technique. »
3
Vérifiez chaque chiffre
Heure de début, durée (2 h 39), nombre de personnes bloquées, bons de préparation retardés : tout doit être dans le journal.
4
Notez les deux résultats
Sur 5, pour chaque critère : fidélité au journal, clarté pour le lecteur, respect du format, rapidité, facilité d’accès.
5
Préparez la restitution
Une différence marquante entre les deux outils, et une phrase : « Sur cette tâche, nous choisirions… parce que… ».
Critères de réussite
  • Même prompt, mot pour mot, dans les deux outils
  • Chaque chiffre vérifié dans le journal
  • Une note lisible par un non-technicien
Bonus
Demandez ensuite à chaque outil : « Qu’as-tu laissé de côté, et pourquoi ? » Comparez les réponses.

Lab 2.1 · La communication d’incident

Objectif
Rédiger, à partir du journal, deux messages sur l’incident FS-02 : un pour les utilisateurs des entrepôts, un pour la direction logistique. Puis ranger le prompt dans une fiche de la bibliothèque.
Fichiers
Orvalis/journal-incident-FS02.docx
Étapes
1
Écrivez le contexte une seule fois
Rôle, faits (heure, service, impact, retour visé), lecteurs.
2
Message aux entrepôts
Les cinq ingrédients :
« Tu es chargé de la communication du support d’Orvalis. FS-02 est indisponible depuis 7 h 52 ; 340 personnes des entrepôts ne peuvent plus ouvrir les bons de préparation ; retour visé vers 10 h 30. Rédige le message aux utilisateurs : un objet et cinq lignes, sans jargon, avec une ligne « Que faire en attendant ? ». »
3
Message à la direction
Relancez dans la même conversation : la direction veut savoir combien de commandes sont retardées, pendant combien de temps, et quel est le risque que ça recommence.
4
Relisez en binôme
Heure, impact, retour visé : exacts ? Zéro jargon dans le message aux entrepôts ?
5
Rangez la fiche
Nom, quand l’utiliser, prompt avec [variables], outil, auteur, date.
Critères de réussite
  • Les cinq ingrédients présents
  • Heure, impact et retour visé exacts
  • Zéro jargon dans le message utilisateurs
Bonus
Faites rédiger le message de fin d’incident, envoyé à 10 h 40, puis comparez le ton avec le premier.

Lab 2.2 · La réponse type à une demande récurrente

Objectif
Créer la réponse type d’Inès pour « Je n’ai plus accès au dossier partagé » : une fiche réutilisable, avec des variables entre crochets, testée sur deux tickets réels du fichier.
Fichiers
Orvalis/tickets-recurrents.xlsx
Étapes
1
Faites poser les questions
Commencez par :
« Je dois écrire une réponse type pour les tickets « Je n’ai plus accès au dossier partagé ». Avant de rédiger, pose-moi les questions dont tu as besoin. »
2
Répondez, puis demandez la réponse type
Elle explique la cause probable, la vérification à faire par l’utilisateur et le délai de traitement. Variables entre crochets : [prénom], [dossier], [délai].
3
Testez sur deux tickets
Choisissez deux messages différents dans le fichier : la réponse type convient-elle aux deux ?
4
Corrigez et rangez
Ajustez la fiche, puis rangez-la dans la bibliothèque de l’équipe.
Critères de réussite
  • Variables entre crochets, faciles à remplir
  • Testée sur deux tickets différents
  • Fiche complète : quand, prompt, outil, auteur
Bonus
Même exercice pour « nouveau téléphone : je ne reçois plus la notification d’authentification ».

Atelier 4 · Auditer une procédure générée par l’IA

Objectif
Une IA a rédigé la procédure de purge des journaux de FS-02. Elle a l’air parfaite. Trouvez les six erreurs avant qu’elle soit publiée.
Fichiers
Orvalis/procedure-purge-IA.docx
Étapes
1
Lisez ligne par ligne
Cherchez quatre types de problèmes : droits trop larges, commandes dangereuses, étapes manquantes, données sensibles.
2
Listez les erreurs
Pour chacune : la ligne, le problème, la correction, la règle de la charte associée.
3
Faites relire l’IA
« Relis cette procédure comme un administrateur prudent. Liste les erreurs de sécurité et les étapes manquantes. »
4
Comparez
L’IA a-t-elle trouvé les mêmes erreurs que vous ? Lesquelles a-t-elle manquées, et pourquoi ?
Critères de réussite
  • Au moins cinq erreurs trouvées sur six
  • Une correction proposée pour chacune
  • Une règle de la charte associée à chacune
Bonus
Réécrivez la procédure corrigée avec l’IA, en lui donnant votre liste d’erreurs.

Lab 7.3 · Votre premier script en vibe coding

Objectif

« Objectif : je veux l’espace libre de tous les disques des serveurs listés. Environnement : Windows, PowerShell 5.1, mon compte habituel. Entrée : serveurs.txt, un nom par ligne.
