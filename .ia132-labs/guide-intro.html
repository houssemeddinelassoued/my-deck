Mode d’emploi

Chaque lab est indépendant : un dossier, un objectif, un point de départ et des tests qui disent quand c’est terminé. Vous pouvez en reprendre un à tout moment, dans l’ordre que vous voulez, après la formation.

1 · Récupérer le dépôt

  1. Ouvrez https://{{REPO}} et cliquez sur Fork : vous obtenez votre propre copie, où vous pourrez pousser et ouvrir des pull requests.
  2. Clonez votre fork, puis vérifiez votre poste : 
    git clone https://github.com/<votre-compte>/ia132-labs.git
cd ia132-labs
python scripts/verifier_env.py
  3. Python : python -m venv .venv, activez-le, puis pip install -r requirements-dev.txt. TypeScript : rien à installer, Node.js 22.18+ exécute les fichiers .ts directement.
  4. Faites le lab 00 : deux tests verts et votre assistant qui « voit » le dépôt.

2 · Le cycle de chaque lab

Rouge → vert

Au départ, la plupart des tests échouent : c’est l’exercice. Le lab est terminé quand ils passent, sans modifier les tests (sauf consigne). 
pytest labs/lab04-debogage      # Python
npm run test:lab04              # TypeScript

L’IA propose, vous décidez

Relisez chaque suggestion et chaque diff. Lancez les tests après chaque changement. Un commit par étape réussie : git restore . annule une étape ratée.

Classe virtuelle

Chacun travaille sur son poste, minuteur à l’écran. Points d’étape réguliers : répondez au micro « étape 1, 2 ou 3 ». Bloqué ? Dites-le : partage d’écran de 2 minutes.

Confidentialité

Aucun code ni donnée de votre entreprise dans ces exercices. Les projets et les données des labs sont fictifs.
