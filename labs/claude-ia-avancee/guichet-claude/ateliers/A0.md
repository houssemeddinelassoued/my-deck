# Atelier 0 · Préparer son poste

> Jour 1, 9 h 20 · 5 minutes · individuel

## Objectif

Pouvoir travailler : dépôt cloné, stack choisie, Claude Code connecté, simulateur et application qui répondent.

## Prérequis (fiche d’accueil, envoyée une semaine avant)

| Pour tous | Selon la stack choisie |
|---|---|
| Git · Node.js 22.18 ou plus récent · application de bureau Claude (onglet Code) ou claude.ai/code · Claude Code en ligne de commande (`claude`), connecté à votre compte Team ou Enterprise | **TypeScript** : rien de plus (Node suffit) · **Python** : uv · **Java** : JDK 21+ et Maven 3.9+ · **.NET** : SDK .NET 8+ |

## Étapes

1. Clonez votre copie du dépôt dans un dossier simple, non synchronisé (pas OneDrive) :
   ```bash
   git clone <votre copie de guichet-claude>
   cd guichet-claude
   ```
2. Choisissez votre stack et installez ses dépendances (une seule fois) :
   ```bash
   node guichet.mjs init ts        # ou python, java, dotnet
   ```
3. Vérifiez le poste :
   ```bash
   node guichet.mjs poste
   ```
   Chaque ligne doit être verte. La ligne « Claude Code » est essentielle : c’est le moteur réel des Ateliers 1 et 2.
4. Testez le mode non interactif de Claude Code :
   ```bash
   claude -p "Dis bonjour en une phrase"
   ```
5. Dans deux terminaux, lancez le simulateur puis l’application :
   ```bash
   node guichet.mjs simu          # terminal 1 : http://localhost:8787
   node guichet.mjs lancer        # terminal 2 : http://localhost:3000
   ```
   Ouvrez http://localhost:3000 : le formulaire et le tableau de bord s’affichent. Une demande soumise renvoie pour l’instant « À compléter » : c’est normal, vous construirez le pipeline à l’Atelier 3.
6. Ouvrez le dossier du dépôt dans l’application Claude (onglet Code) et demandez : « Explique ce dépôt en trois phrases. »

## Réussite

```bash
node guichet.mjs verifier A0
```

## En cas de souci

- `claude` introuvable ou non connecté : lancez `claude`, puis `/login`. Sans accès à Claude Code, travaillez avec le simulateur et suivez la partie « moteur réel » sur l’écran projeté.
- Port 3000 ou 8787 occupé : `PORT=3100 node guichet.mjs lancer`, `SIMU_PORT=8797 node guichet.mjs simu` (ou fichier `.env`, voir `.env.exemple`).
- Proxy d’entreprise : voir l’annexe F du guide (dépannage).
