# Atelier 5 · Défi final : la demande métier d’Oasis Digital

> Jour 2, 14 h 25 – 14 h 55 · 30 minutes · individuel · en autonomie, avec tout le harnais

## La demande

> « Nos clients européens écrivent en anglais. Détectez la **langue** de chaque demande, affichez-la dans le tableau de bord, et routez les demandes en anglais vers l’**équipe Europe** (les autres vers l’équipe Tunis). »

## Règles du jeu

Vous êtes le chef de projet : Claude Code fait le travail, vous cadrez et vous vérifiez.

1. **Plan** : mode Plan, faites proposer un plan, corrigez-le, puis enregistrez-le dans `decisions/langue.md` (plan retenu, corrections apportées).
2. **Implémentation** : la Skill `ajouter-champ` doit se déclencher ; les hooks tournent à chaque modification.
3. **Règle métier en code** : la langue et l’équipe sont calculées par le domaine (déterministe, testable), pas demandées au modèle. Cas de référence : `donnees/langue-cas.json` (français, anglais, message mélangé, message vide).
4. **Relecture** par `relecteur-securite`, corrections, puis commit.

Fichiers de départ (une fonction par trou) :

| TypeScript | Python | Java | .NET |
|---|---|---|---|
| `ts/src/domaine/langue.ts` | `python/guichet/domaine/langue.py` | `…/domaine/Langue.java` | `dotnet/Guichet/Domaine/Langue.cs` |
