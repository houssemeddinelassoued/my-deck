Formation de 2 jours qui suit le [programme officiel Technologia](https://www.technologia.com/formations/feuille-de-route-pour-lia-agentique---une-exploration-complete-des-agents-dia) : 10 modules (Jour 1 : comprendre les agents · Jour 2 : construire la feuille de route), avec QCM, ateliers minutés, simulateurs interactifs, un fil rouge (Boréal Distribution) et les notes du formateur sur chaque page.

<img src="docs/preview/ia134-01.png" alt="Couverture de la formation IA134" width="49%"> <img src="docs/preview/ia134-30.png" alt="Consignes d'atelier avec chronomètre intégré" width="49%">

### Les formations métier (1 journée)

Assistant administratif, RH, marketing & communication, relation client, 20 outils IA : ces cinq formations partagent la même structure. On commence par situer l'IA dans le métier, puis chaque module traite une tâche concrète (rédiger une offre d'emploi, répondre à une réclamation, décliner une idée en contenus…) et se termine par un atelier. Une entreprise fictive sert de fil rouge et revient dans les exemples, jusqu'au cas final. La formation **20 outils IA** consacre une page à chaque outil : fonctions clés, exemple de prompt et de réponse, points de vigilance.

### GitHub Copilot · Niveau avancé

Six modules : prompt engineering avancé, modules et architectures, tests automatisés, optimisation et refactoring, sécurité et audit du code généré, Copilot en équipe. Les TP portent sur une même API REST de réservation de salles (SalleLibre), au choix en TypeScript, Python, Java ou C#.

#### Comment une machine apprend

Un fil rouge du début à la fin : **prédire le loyer d'un appartement à partir de sa surface**. Puis un second exemple, la détection de spam, pour la classification.

| Chapitre | Ce qu'on y voit |
| --- | --- |
| **Introduction** | Programmer ou apprendre · supervisé, non supervisé, par renforcement · la recette en six étapes |
| **01 · Données** | Un jeu de données est un tableau (x, y) · encoder catégories, images et échelles |
| **02 · Modèle** | Une droite ŷ = w·x + b et ses réglages · classer avec une frontière et une sigmoïde |
| **03 · Erreur** | Les résidus et la MSE, dessinée en carrés · le paysage de l'erreur |

| **05 · Généralisation** | Entraînement / validation / test · sous- et sur-apprentissage · courbes d'apprentissage · précision et rappel |
| **06 · Au-delà** | Arbres de décision · réseaux de neurones · k-means |

| **06 · Entraînement** | Le pré-entraînement · du compléteur de texte à l'assistant |
| **Conclusion** | Ce que ce mécanisme implique |

## Présenter

Ouvrez une présentation, puis le menu **Present** : **Play** (dans la fenêtre), **Fullscreen**, ou **Presenter mode**. Beaucoup de pages se construisent clic par clic : chaque **→** révèle l'étape suivante avant de passer à la page d'après. Une touche maintenue enfoncée (ou le bouton d'une télécommande) n'avance que d'une étape à la fois.

| Touche | Action |
| --- | --- |
| `→` · `Espace` / `←` | Étape ou page suivante / précédente |
| `F` | Lancer en plein écran |
| `O` | Vue d'ensemble des pages |
| `P` | Ouvrir la vue présentateur |
| `B` · `W` | Écran noir · écran blanc |
| `L` | Pointeur laser |
| `?` | Aide des raccourcis |
| `Esc` | Fermer / quitter |

La **vue présentateur** affiche les notes de l'orateur, la page suivante et un minuteur. Ouvrez-la dans une seconde fenêtre du même navigateur : elle suit la présentation. Pour démarrer directement à une page précise, ajoutez `?p=<numéro>` au lien (par exemple [`/s/ml-explique?p=11`](https://houssemeddinelassoued.github.io/my-deck/s/ml-explique?p=11)).

### En ligne ou en local ?

Le site GitHub Pages est la version **statique** : idéale pour présenter et partager. Les outils d'édition d'open-slide (inspecteur, panneau Design, gestion des images, modification des notes, dossiers) ont besoin du serveur de développement, donc d'une installation locale.

| | GitHub Pages | `npm run dev` |
| --- | :---: | :---: |
| Lire, naviguer, plein écran, vue présentateur | ✅ | ✅ |
| Lire les notes de l'orateur | ✅ | ✅ |
| Modifier les slides avec rechargement à chaud | — | ✅ |
| Inspecteur, panneau Design, assets | — | ✅ |
| Ranger les présentations en dossiers, les protéger par mot de passe | — | ✅ |

## Présentations générées

Les neuf formations ne s'éditent **pas** dans leur `index.tsx` : ce fichier est produit par un script, et toute modification manuelle serait écrasée à la reconstruction suivante. Chaque formation a son dossier de sources : un `kit.tsx` (thème et composants : cadre, chronomètre, quiz, ateliers…) et des fragments, un par module, qui contiennent les pages et les notes. Modifiez les fragments ou le kit, puis reconstruisez. Le script vérifie aussi les types avec `tsc`.

## Déploiement

Chaque push sur `main` déclenche [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) :

1. `npm ci`, dont le `postinstall` réapplique le correctif d'open-slide (le job échoue s'il ne s'applique pas), puis `npm run build` ;
2. le chemin de base `/<nom-du-dépôt>/` est injecté dans `open-slide.config.ts` **sur la machine de CI uniquement**, pour que les liens fonctionnent sous `houssemeddinelassoued.github.io/my-deck/` (en local, le site reste servi depuis `/`). Si le dépôt est renommé, le chemin suit automatiquement ;
3. `index.html` est copié en `404.html`, pour que les liens directs comme `/s/ml-explique` s'ouvrent ;
4. le dossier `dist/` est publié sur GitHub Pages.

Le déploiement peut aussi être relancé à la main depuis l'onglet **Actions**. Le dépôt contient aussi `netlify.toml` et `vercel.json`, pour publier le même site sur Netlify ou Vercel (servi depuis la racine `/`).

## Créer une présentation

Une présentation, c'est un dossier `slides/<id>/` avec un `index.tsx` qui exporte un tableau de pages React. Chaque page s'affiche sur un canevas fixe de **1920 × 1080** pixels.

```tsx
// slides/ma-presentation/index.tsx
import type { Page, SlideMeta } from '@open-slide/core';

const Couverture: Page = () => (
  <div style={{ width: '100%', height: '100%', padding: 140 }}>
    <h1 style={{ fontSize: 150 }}>Bonjour</h1>
  </div>
);

export const meta: SlideMeta = { title: 'Ma présentation' };
export const notes = ["Ce que je dis sur la couverture."];
export default [Couverture] satisfies Page[];
```

Le dépôt est configuré pour **Claude Code** : demandez « fais une présentation sur… » et le skill `create-slide` prend le relais. `apply-comments` applique les commentaires laissés avec l'inspecteur, et `create-theme` crée un thème réutilisable. Les règles du dépôt sont dans [`CLAUDE.md`](CLAUDE.md).

Une fois la présentation poussée sur `main`, elle est en ligne à l'adresse `https://houssemeddinelassoued.github.io/my-deck/s/<id>`.
